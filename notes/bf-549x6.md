## Analysis Summary
The functionality to reject NEEDLE-internal-config investigation tasks in target-repo auto-decomposition **was already fully implemented and tested** in the codebase prior to this bead. No code changes were required.

The implementation consists of two components:

### 1. Mitosis Module (`src/mitosis/mod.rs`)

**Detection Function** (lines 566-611):
- `detects_needle_internal_config(bead: &Bead)` checks for NEEDLE-internal configuration patterns
- Patterns include: "pluck configuration", "exclude_labels", "bead discovery", "starvation alert", "needle dispatch", "strand configuration", "worker configuration", "bead filtering", "candidate exclusion"
- Returns `true` if bead title/body contains these patterns

**MitosisEvaluator Integration** (lines 105-117):
- Before dispatching agent for mitosis analysis, checks if bead references NEEDLE-internal config
- If detected, emits `MitosisOutOfScope` telemetry and returns `MitosisResult::OutOfScope`
- This prevents child bead creation for these tasks

### 2. Pluck Strand (`src/strand/pluck.rs`)

**Split Trigger Filter** (lines 474-496):
- Before triggering `StrandResult::Split`, checks if candidate references NEEDLE-internal config
- If detected, filters out the candidate and re-evaluates remaining candidates
- Prevents split from being triggered for these beads in the target workspace
