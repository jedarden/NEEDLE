## Acceptance Criteria Verified

- `ATEXIT_WORKER_STATE` is a `static Mutex<Option<AtexitWorkerState>>`

### ✅ Path survives across async task boundaries  
- Set once during `install_signal_handlers()` (line 948)
- Persists for the entire lifetime of the process
- Retrieved by atexit handler on process termination

### ✅ Shutdown handler can retrieve the path
- Atexit handler retrieves the path from the mutex (line 183)
- Removes the heartbeat file to prevent stale detection

## Dual Cleanup Mechanism

Two mechanisms ensure heartbeat cleanup:

1. **Graceful shutdown**: `HealthMonitor::stop()` removes the heartbeat file
2. **Unexpected termination**: Atexit handler removes the heartbeat file using the stored path
