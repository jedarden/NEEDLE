- **Location:** `src/routing.rs` line 60
- **Purpose:** Detects if a pattern contains glob-style wildcards (* or **) that need conversion to regex
- **Returns:** `bool` (true if glob conversion is needed, false otherwise)

### Algorithm
The function uses a two-step heuristic:
1. First checks for regex metacharacters (^$()[]{}+?|\ and .*) - if found, it's a regex pattern
2. If no regex features found, scans for unescaped * characters - if found, it's a glob pattern
