## Implementation Details

The function is implemented as a standalone utility function in the health module:

```rust
pub fn cleanup_heartbeat_file(path: &Path) -> Result<()> {
    match std::fs::remove_file(path) {
        Ok(_) => Ok(()),
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => {
            // File doesn't exist - this is success (idempotent cleanup)
            tracing::debug!(
                path = %path.display(),
                "heartbeat file does not exist, skipping cleanup"
            );
            Ok(())
        }
        Err(e) => {
            // Unexpected error - return with context
            Err(e).with_context(|| {
                format!(
                    "failed to remove heartbeat file: {}",
                    path.display()
                )
            })
        }
    }
}
```

This implementation provides:
- **Idempotent cleanup**: Calling multiple times is safe
- **Clear error messages**: Uses `anyhow::Context` for descriptive errors
- **Proper logging**: Debug log for successful cleanup of non-existent files
- **Error propagation**: Unexpected failures are returned to the caller
