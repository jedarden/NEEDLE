### p95 Implementation Details

The p95 implementation is located in `src/stats/mod.rs`:

- **Function**: `calculate_p95(latencies: &[u128]) -> u128`
- **Algorithm**: Linear interpolation (matches Criterion.rs methodology)
- **Features**:
  - Handles edge cases (empty, single element, two elements)
  - Sorts input internally (works with unsorted data)
  - Uses formula: `rank = 0.95 * (n - 1)`, then linear interpolation
  - Rounds to nearest integer with epsilon for floating-point precision
